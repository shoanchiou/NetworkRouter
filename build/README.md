# Build and release (draft)

Windows x64, .NET SDK 8, Visual Studio 2022 C++ build tools and Inno Setup 6.7.4 or 7.1.1 are required. Obtain Inno Setup from https://jrsoftware.org/isdl.php and verify its Authenticode signature as documented at https://jrsoftware.org/isdl-verify.php. Do not install the application on a production machine to test the installer: use a disposable Windows VM and snapshots.

Build from a clean checkout. The build accepts separately supplied, reviewed release inputs; it must not download or silently substitute executable code. The fixed core file is `mihomo.exe`, SHA-256 `04F8D7FC2B314771E1ECBF15951D59F0E1CB7914503C88CFB6972FF6A824E314`. The corresponding `mihomo-v1.19.32-source.zip` has SHA-256 `135F16D1E309F8C0CE2303C86FD38A38624A229E7185CEB74D1D3A4F0D4B66F1`. The original BindRouter source archive hash is `CEE5BFB6379E178181C069F6EFDB0D658ECED927E2D6AF9D8D94C3DDBD69C294`. Original upstream sources: https://github.com/MetaCubeX/mihomo/tree/v1.19.32 and https://github.com/aydinfarro/BindRouter/tree/v1.2.0. The core's binary and source, upstream attribution and native helpers must be present in the installer.

The uninstaller includes a recovery gate and ownership checks; these have only been checked with mocks, and still require independent review and disposable-VM validation. The candidate setup may be shared locally for evaluation. Installation and removal have not yet been tested on a clean Windows VM; do not describe this as a fully validated release. If published on GitHub, mark the release as a prerelease until that validation is complete. Required validation includes clean install, upgrade, enabled/disabled/paused state, optional paid protection, uninstall and fault injection in disposable VMs, including a failed cleanup that preserves recovery files. Do not run real WFP/SCM/network tests on the developer machine. Release assets should include the setup and a SHA-256 file; code signing and publication require separate owner decisions.

From a Visual Studio x64 Native Tools PowerShell, run `./build/Build-Payload.ps1 -DependencyRoot <reviewed-input-root>`. The input root contains `core/mihomo.exe` and the two archives in `licenses/`; the existing R7 product root has that layout. The script verifies all three hashes before creating a unique payload in ignored `artifacts/`, compiles the native helpers and runs the paid guard offline self-test. On another machine, obtain the exact fixed inputs separately from upstream and verify against the hashes above; no auto-update is performed. Clean-VM installation and removal tests and independent cleanup review remain outstanding; a GitHub release should be marked as a prerelease until these are complete.
